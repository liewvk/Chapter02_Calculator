# Chapter02_Calculator

A C++ calculator project built with CMake.

## 📋 Overview

This is a simple calculator implementation written in C++ as part of Chapter 2 learning exercises. The project demonstrates fundamental programming concepts and is built using CMake for cross-platform compilation support.

## 🛠️ Technology Stack

- **Language**: C++ (88.7% of the codebase)
- **Build System**: CMake (11.3% of the codebase)

## 🚀 Getting Started

### Prerequisites

- C++ compiler (C++11 or later)
- CMake 3.10 or higher

### Building the Project

```bash
# Clone the repository
git clone https://github.com/liewvk/Chapter02_Calculator.git
cd Chapter02_Calculator

# Create a build directory
mkdir build
cd build

# Generate build files and compile
cmake ..
make
```

### Running the Calculator

```bash
./Chapter02_Calculator
```
